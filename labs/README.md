# Activities — Generative AI for Business Presentations

Eight connected activities use the Meridian Foods ReadyWise scenario. Every folder is self-contained and includes detailed instructions, a printable Markdown checklist and an editable sample PowerPoint.

The sample decks demonstrate the named tool workflow and expected quality. They are locally generated, editable worked examples—not claims that a proprietary tool exported the file verbatim.

- Activity 01: Decision-Ready Presentation Brief — PowerPoint + Claude
- Activity 02: AI Tool Fit and Risk Matrix — Canva · Gamma · Napkin · Copilot · PowerPoint
- Activity 03: Executive Story Spine with Claude or Copilot — Claude or Microsoft 365 Copilot
- Activity 04: AI Draft-to-Deck Design Studio — PowerPoint/Copilot · Canva · Gamma · Adobe Express · Presenton · Manus · QuillBot · Prezent
- Activity 05: Evidence-to-Visual Upgrade with Napkin — Napkin + PowerPoint or Canva
- Activity 06: Delivery and Q&A Rehearsal — PowerPoint Presenter View + Microsoft 365 Copilot
- Activity 07: Negotiation Deck Challenge — Claude + PowerPoint
- Activity 08: Presentation Review and Improvement Sprint — PowerPoint + Canva + Claude or Microsoft 365 Copilot
