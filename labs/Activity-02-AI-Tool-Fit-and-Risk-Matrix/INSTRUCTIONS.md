# Activity 02 — AI Tool Fit and Risk Matrix

**Course:** Generative AI for Business Presentations (TGS-2026061325)  
**Duration:** 40 minutes  
**Tools:** Canva · Gamma · Napkin · Copilot · PowerPoint  
**Output:** A weighted matrix comparing at least six tools and a diagram of the approved human-in-the-loop workflow.

## Objective

Select an ai presentation workflow based on task fit, editability, governance and export requirements.

## Scenario

Meridian's team can use PowerPoint, Microsoft 365 Copilot, Canva, Gamma, Napkin and Claude. A manager also proposes Presenton, Manus, QuillBot and Prezent. The source pack includes internal financial assumptions and customer research.
Choose a safe production chain that gets a first draft quickly while keeping the final deck editable, branded, accessible and evidence-controlled.

## Detailed instructions

1. **Set the task.** Use the Activity 1 brief. Define the required deliverables: editable PPTX, PDF, speaker notes, source record and brand compliance.

2. **Set criteria.** Create columns for source grounding, story quality, visual quality, brand control, collaboration, export, accessibility, privacy and cost. Assign weights totalling 100%.

3. **Classify the source pack.** Label each item Public, Internal or Restricted. Only use tools approved for the data classification.

4. **Build a shortlist.** Include PowerPoint/Copilot, Canva, Gamma, Napkin and Claude plus at least one of Adobe Express, Presenton, Manus, QuillBot or Prezent.

5. **Use one test prompt.** Give each generation tool the same public-safe brief and request the same nine-slide outline. Save the prompt and output date.

6. **Inspect controls.** Test whether layouts, charts, notes, citations and brand assets remain editable. Export a PPTX where supported and open it in PowerPoint.

7. **Score evidence.** Rate each tool 1–5 using observed output, not marketing claims. Record a short rationale and limitation.

8. **Design the chain.** Assign tools to briefing, story, visuals, production, review and final export. Put a named human approval gate before external use.

9. **Document the decision.** State the chosen workflow, rejected alternatives, data restrictions and fallback if export or access fails.

## Suggested timing

- 5 minutes — Define evaluation criteria and weights
- 10 minutes — Review capabilities and governance constraints
- 12 minutes — Run a same-brief comparison
- 8 minutes — Score outputs and export quality
- 5 minutes — Design the production chain

## Submission

Submit the completed activity artefact, the checklist and the editable presentation file. Record all AI tools, prompts, sources and human changes used.

## Debrief

The matrix compares at least six tools across task fit, source grounding, brand control, collaboration, export and data risk.
